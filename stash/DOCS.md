# Stash

Self-hosted home inventory & barcode manager as a Home Assistant app.

## How to use

1. Start the app and open it via **Ingress** (sidebar: Stash).
2. On first launch, create the admin account at the login screen.
3. Optionally set `app_public_url` for QR deep-links that open outside Ingress.

Persistent data lives in the app `/data` folder (Postgres, uploads, secrets).
